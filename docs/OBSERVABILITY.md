# Observability

Atualizado em: 17/06/2026

## Ferramentas

- Sentry front e back.
- PostHog.
- Google Analytics.
- Web vitals enviados ao backend.
- Health/readiness/liveness.

## KPIs tecnicos

- Erros por rota.
- Latencia API p95/p99.
- LCP/FCP/CLS/TBT das paginas publicas.
- Taxa de erro em webhooks.
- Jobs/crons falhando.
- Conexoes DB/Redis.

## KPIs de produto

- Leads por origem.
- Tempo de primeiro atendimento.
- Leads parados.
- Visitas marcadas/realizadas/canceladas.
- Propostas.
- Contratos.
- Conversao por corretor.
- Imoveis sem atualizacao.
